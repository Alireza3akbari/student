# Student Score Checker ✅

A simple Python program to enter student names and scores,  
then evaluate their status based on their score.

### 🎯 Features
- Enter student name and score
- Automatically assigns evaluation:
  - Excellent (>= 18)
  - Good (>= 15)
  - Needs Improvement (>= 10)
  - Failed (< 10)
- Displays results at the end

### ▶️ How to Run
```bash
python main.py
